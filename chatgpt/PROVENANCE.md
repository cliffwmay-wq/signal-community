# Provenance and platform adaptation

This package is a faithful ChatGPT adaptation of the supplied **Signal — free community release kit**, whose Claude Code plugin declares version 0.2.0. The original installable files are preserved only in the builder's local copy. Public Claude packages are rebuilt without the internal sharing draft; see the project's `SOURCE.md` for provenance.

The ChatGPT skill begins with the supplied Claude chat skill's `SKILL.md`, references, and inspector. Changes in this companion are limited to ChatGPT service wording, the installed script path, a portable plugin manifest, a first-use example, privacy/setup notes, and package tests. The core editorial rules, Voice DNA method, anti-pattern guidance, quality gates, and scanner behavior remain from the supplied release.

This is not a rewrite as Temper. Signal remains focused on the author's words, meaning, and control. The scanner can run only in a host with local file and Python access; it is optional to the writing workflows.
