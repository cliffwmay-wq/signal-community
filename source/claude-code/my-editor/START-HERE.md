# Signal — start here

**Write like yourself, with a little help from Claude.**

Signal is free. It's useful even if you've never installed a skill before.

## If you use Claude in a browser

1. Find the separate file `Signal-Claude-Skill.zip` in the release bundle.
2. In Claude, go to **Customize → Skills → + → Create skill → Upload a skill**, choose the ZIP, and enable it. If necessary enable code execution / file creation in Claude settings.
3. Paste text and say: **“Use Signal. Tighten this without changing my point or making it sound generic.”**

Want it to sound *more* like you? Upload a few pages of **your original writing** (handwriting, older essays, notes). Ask: **“Use Signal to create a provisional Voice DNA profile. Show the evidence and let me correct it. Don't save it yet.”**

## If you use Claude Code

Unzip `Signal-Claude-Code-Plugin.zip`, then run:

```bash
claude --plugin-dir /path/to/my-editor
```

Try `/my-editor:editor`, `/my-editor:voice`, `/my-editor:audit`, or `/my-editor:inspect`.

## What it won't do

It won't tell you your text is “99% human,” prove who wrote it, or silently strip meaningful provenance. It won't save your personal writing samples by default. It won't invent a personality to make AI writing seem human.

**No account for Signal. No subscription. No Signal telemetry.** Claude's own account requirements, limits, and data policies still apply.
