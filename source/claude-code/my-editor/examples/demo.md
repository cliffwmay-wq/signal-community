# Signal example — fictional demonstration

This example is **fabricated for documentation**, not a real person's writing or a detector benchmark.

### Before

In today's rapidly evolving workplace landscape, it is imperative that we leverage robust cross-functional synergies to unlock enhanced operational efficiencies. This transformative initiative will empower our teams and drive seamless alignment across all stakeholders.

### Signal revision (Compress)

We need the operations and support teams working from the same plan. That should cut duplicate effort and make it clearer who owns each handoff.

### Why

The revision replaces unsupported hype with an actor, a proposed mechanism, and an observable effect. **But** it also adds specific actors and duplicate effort that were absent from the original. In a real edit, Signal should **flag those details as proposed interpretations and ask the author to confirm them**. It must not silently turn them into established facts.

### Strict meaning-preserving alternative

This initiative aims to improve efficiency by helping teams coordinate their work. Its specific responsibilities, measures and expected effects still need to be defined.

This second version is what Signal should prefer when no supporting context is supplied.
