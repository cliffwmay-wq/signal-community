# Signal — Claude upload edition

This folder is a standalone Agent Skill for Claude chat, designed for people who do not use a terminal.

## Install

1. Upload the **Signal-Claude-Skill.zip** release archive at Claude → Customize → Skills → + → Create skill → Upload a skill.
2. Enable Signal.
3. Ask: “Use Signal to tighten this draft without changing my meaning or voice.”

You can also ask Claude to build an optional Voice DNA profile from your own original writing samples. Review the profile before saving it. Never upload sensitive samples merely to build a profile.

The bundled Python inspector can be used when the environment supports local script execution; it is not a provider watermark detector.

See the complete distribution README in the Claude Code plugin package. MIT licensed. No Signal telemetry or subscriptions; Claude account terms still apply.
